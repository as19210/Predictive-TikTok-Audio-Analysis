# TikTok Audio Popularity Prediction

Predicting TikTok audio popularity using Python, exploratory data analysis, and machine learning.

## Project Overview

This project investigates which musical characteristics influence TikTok audio popularity, using a dataset of trending tracks. The goal was to identify predictive relationships between audio features and popularity scores, with potential applications in music marketing and trend forecasting.

## Tools & Technologies

Python: Pandas, NumPy, Matplotlib, Seaborn

## Machine Learning: Scikit-learn, Linear Regression, Multiple Linear Regression, Random Forest

## Techniques: Data Cleaning, Exploratory Data Analysis, Correlation Analysis, Regression Modeling, Feature Importance, Partial Dependence Plots

## Methodology

Cleaned and preprocessed a dataset of 6,746 tracks, retaining 3,196 observations for analysis.

Explored relationships between popularity and musical attributes such as danceability, energy, valence, loudness, tempo, and duration.

Developed and compared regression-based machine learning models to predict popularity scores.

Used correlation heatmaps, feature importance rankings, and partial dependence plots to interpret model behavior.

## Results & Insights

Random Forest achieved an R² of approximately 0.55, outperforming linear regression models.

Loudness, valence, and duration emerged as important predictive features.

Identified nonlinear relationships between musical characteristics and popularity.

Found that audio features alone cannot fully explain virality, which is also influenced by trends, engagement, and platform dynamics.
